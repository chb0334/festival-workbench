📥 节日素材 · 书签采集器

这是一个浏览器书签，用来绕过 Williams-Sonoma 等网站的反爬——它在你自己的浏览器里运行（你家/公司的 IP 和真人指纹，网站不会拦），把商品页的信息读出来，再导进工作台。

第一步：把下面的按钮拖到浏览器书签栏

🎃 抓取当前商品

若书签栏没显示：Chrome 按 Ctrl+Shift+B 调出；然后把上面橙色按钮拖进去。

第二步：去 Williams-Sonoma 抓图

  1. 打开任意一个 WS 商品页（如节日餐具/盘子/杯子）。
  2. 点击书签栏的「🎃 抓取当前商品」。
  3. 右下角弹出面板，显示已抓取的信息；可连续抓多件。
  4. 点「导出全部(N)」下载一个 .json 文件。

第三步：导入工作台

  1. 打开节日素材工作台，左侧「其他」→ 点「📥 手动录入 / 导入」。
  2. 把刚才的 .json 拖进弹窗（或点选文件），点「导入」。
  3. 条目立即出现在「全部」里，节日/类型按标题自动识别。

手动录入的条目只存在你本机浏览器（刷新不丢，换浏览器/清缓存会丢）。想并入共享库，把导出的 JSON 发给管理员写入文件即可。

图片用原始 CDN 远程链接，在真实浏览器中正常显示；如需导出到独立站/Pinterest，再由本地脚本把图下载到本地即可。
