安装「花瓣捕获·带热度」书签（抓“节日+盘子”图 + 热度）

橙色按钮是书签链接。按住拖到浏览器收藏夹栏松手即装好，不用复制代码。

⚠️ 直接拖，别右键复制链接/手动粘贴，会弄坏代码。

📸 拖我到收藏夹栏：花瓣捕获

一、装书签（只做一次）

  1. 显示收藏夹栏：Chrome/Edge 按 Ctrl+Shift+B（Mac Cmd+Shift+B）；Firefox 菜单 ☰ → 书签 → 勾「书签工具栏」。
  2. 鼠标左键按住上面蓝色按钮，拖到收藏夹栏松手。栏里出现「花瓣捕获」即装好（覆盖旧的可删掉旧的）。

二、在 3 个“节日+盘子”搜索页各跑一次（复活节/情人节/独立日暂不做）

  1. 地址栏逐个打开（每行一个，整段粘贴回车）： 
    https://huaban.com/search/?q=万圣节盘子
https://huaban.com/search/?q=感恩节盘子
https://huaban.com/search/?q=圣诞节盘子
    打不开就去掉斜杠试 https://huaban.com/search?q=万圣节盘子；若要求登录先登录。
  2. 页面打开、缩略图出来后，点收藏栏「花瓣捕获」。它会自动滚动加载并抓取本页所有花瓣图、自动下载成 <hash>.webp，并顺带抓取每张的热度（采集/喜欢数）。
  3. 浏览器右上角弹“是否允许下载多个文件”→ 点「允许」。左上角绿框显示“本页匹配 N 张 / 本页热度命中 M/N / 累计 K 张”。
  4. 3 个页面各跑一遍。绿框里的数字是累计（跨页用浏览器 localStorage 累加，不会丢）。

三、导出元数据 + 交给我

  1. 跑完 3 页后，在任意一个花瓣页点绿框里的「下载全部元数据JSON」→ 得到 huaban_capture.json（含每张图的 hash / 原地址 / 来源 pin 页 / 节日 / 热度 / 诊断）。也可用「复制全部」直接复制。
  2. 把两样东西给我：
    • ① huaban_capture.json（或复制的文本）；
    • ② 下载文件夹里那批 .webp 文件（整堆拖进仓库 images/huaban/，或本地 git 提交）。
  3. 跟我说“盘子类抓好了”→ 我跑 rebuild_huaban.py，把工作台花瓣网板块整体替换成这批“节日+盘子”图（按节日归类、图指向本地、有热度的填“收藏热度”证据）、提交发布。

本次会重新下载图（覆盖同名，无害），目的是让抓到的 hash 与图 100% 对齐，同时带回每张图的热度（花瓣网采集/喜欢数）。绿框里的“热度命中”若明显偏低（比如 <50%），多半是花瓣网页面结构变了，把 JSON 发我，我从里面的诊断字段校准选择器后再让你跑一次。
