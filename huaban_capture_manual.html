之前拖拽安装的书签十有八九是空壳（网址不是代码）。请先删掉工具栏上旧的那个（右键→删除），再按下面做。

第 2 步：新建书签并粘贴

  1. 在 Firefox 里右键点击顶部书签工具栏的空白处 → 选「新建书签…」（如果没有这个选项：菜单 ☰ → 书签 → 管理书签 → 顶栏「导入和备份」旁的 ⭐/组织 → 新建书签）。
  2. 弹窗里填两项：
    • 名称：花瓣捕获
    • 网址（位置/URL）：把刚复制的代码原样粘贴进去（Ctrl+V），粘贴后确认以 javascript: 开头。
  3. 点「保存」。工具栏上出现「花瓣捕获」。

第 3 步：到花瓣搜索页点它

  1. 打开 https://huaban.com/search/?q=万圣节盘子，等缩略图出来。
  2. 点工具栏「花瓣捕获」→ 左上角出现黑底绿字框「本页匹配 N 张」→ 图片自动下载。
  3. 弹“允许下载多个文件”点允许。
  4. 6 个“节日+盘子”搜索页各跑一次，最后点绿框「下载全部元数据JSON」，把 JSON + .webp 一起交给助手。

若第 3 步还是没反应：右键工具栏「花瓣捕获」→ 属性，把「位置」字段开头一小段截图发我，我立刻判断哪里断了。
