安装「花瓣图下载」书签

下面橙色按钮是书签链接。用鼠标按住拖到浏览器收藏夹栏松手即装好，不用复制代码。

⚠️ 直接拖，别右键复制链接/手动粘贴，会弄坏代码。

📥 拖我到收藏夹栏：花瓣图下载

一、先把书签装好（只做一次）

  1. 显示收藏夹栏（书签要放在这里）：
    • Chrome/Edge：按 Ctrl+Shift+B（Mac 是 Cmd+Shift+B）；或右键浏览器顶部地址栏右侧空白处 → 勾选「显示书签栏」。
    • Firefox：菜单 ☰ →「书签」→ 勾选「书签工具栏」。
  2. 用鼠标左键按住上面橙色按钮，拖到收藏夹栏上任意位置松手。收藏夹栏里出现一个名为「花瓣图下载」的按钮，即装好。
  3. （验证）点一下收藏夹栏的「花瓣图下载」——此刻不在花瓣网，它会提示“本页没匹配到花瓣图”，说明书签已生效，关掉提示即可。

二、下载 201 张图（每个节日页跑一次，共 6 次）

  1. 在地址栏逐个打开下面 6 个搜索页（整段复制，每行一个，粘到地址栏回车；中文直接粘就行）： 
    https://huaban.com/search/?q=万圣节
https://huaban.com/search/?q=感恩节
https://huaban.com/search/?q=圣诞节
https://huaban.com/search/?q=复活节
https://huaban.com/search/?q=情人节
https://huaban.com/search/?q=独立日
    若打开后是空白/要求登录，先登录花瓣网再重开；若页面打不开，去掉 URL 里的斜杠试 https://huaban.com/search?q=万圣节。
  2. 页面打开后，点收藏夹栏的「花瓣图下载」。书签会自动向下滚动（约 15 秒）把图片加载出来，然后弹窗显示“将下载 N 张”。
  3. 弹窗点「确定」开始下载。浏览器右上角可能弹出“是否允许下载多个文件”→ 点「允许」（务必点允许，否则只下一张）。
  4. 左上角绿色提示变成“✓ 完成”即该页下载完。若想更保险，手动再滚一下页面到底，重跑一次书签（重复文件浏览器会覆盖，无害）。
  5. 把这 6 个页面各跑一遍，下载文件夹里会累积一批 <hash>.webp 文件，总共 201 个。

三、把图放进仓库（二选一）

方法 A（最简单，网页操作，无需 git）：

  1. 打开你的 GitHub 仓库页面，进入 images/huaban/ 目录（没有就新建文件夹）。
  2. 点 Add file → Upload files，把下载文件夹里的 201 个 .webp 一次性拖进去，写个提交说明，Commit changes。

方法 B（本地 git，适合熟练）：

  1. 把 201 个 .webp 复制到仓库的 images/huaban/ 目录。
  2. 命令行：git add images/huaban/ && git commit -m "add huaban images" && git push。

四、告诉我一声

图传上去后，跟我说“图传好了”，我立刻跑 fix_huaban_imgs.py 改写工作台引用（按 hash 精准匹配）、提交并发布。之后永久有图，不再受花瓣签名过期影响。若我这边 dry-run 发现还缺几张，会告诉你具体缺哪些 hash，你补下即可。

原理：花瓣图只有你本机浏览器（已登录/过验证）才取得到字节——沙箱数据中心 IP 被花瓣 CDN 封（HTTP 567）且花瓣禁跨域，所以我无法代下。书签在你浏览器里把图存成本地文件，再由仓库托管，一劳永逸。
